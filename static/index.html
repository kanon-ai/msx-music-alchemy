ALCHEMY / SOUND LAB

音源ごとに独立した音色を作成・試奏します。楽曲は変更しません。保存した自作音色は譜面側の音色一覧から選べます。

C1〜B6を横スクロール。オクターブ選択でPCキーの音域を移動。鍵盤クリック / PCキーはZ段 → A段 → Q段 → 数字段の順に48半音（4オクターブ）を単音試奏。JIS配列の「ろ」「¥」も使用。キーを離すと停止（音符は追加しません）。

入力中は曲を変更しません。反映で選択パート全体の音符を置換します（Undo対応・反映時は再生停止）。

書き方・対応コマンド

例：o4 l8 v12 q8 cdef gab>c
c～b / r：音符・休符、+ # -：臨時記号、o1～6：オクターブ、< >：上下、l：基本音長、v0～15：音量、q1～8：ゲート。付点・^音長連結・[cdef]2：有限ループ（最大32回）に対応。; 以降はコメント。

4分音符＝96 tick。%48＝4分音符（MGSC同様）、!96＝96 tick（本エディタ拡張）。音符直後の {JSON} は奏法などの個別設定です。再取得時に自動生成し、編集しなければ保持します。音色は既存の音色欄で設定してください。テンポ・音色定義・複数パートのMMLはここでは扱いません。

OPM有効時はMGSDRV出力できません。WAV・VGM・JSONをご利用ください。実機用C/BINにはSFGへの書き込み実装が必要です。

MGSの奏法・タイミング・ドラム減衰はMGSDRV向けに近似変換します。C / BINには同梱プレイヤーと音源書き込み関数の実装が必要です。実機動作は未検証です。

作曲とAI連携

編集

ピアノロールをクリックして追加。ノートをドラッグして移動、右端をドラッグして長さを変更。右クリックまたはDeleteで削除。Ctrl+Z / Ctrl+Yで取り消し・やり直し。

ステップ入力は音名ボタンまたはZ〜Mで入力。トラックは単音です。和音は別チャンネルに分けます。Mはミュート、Sはソロ試聴です。

AIが作曲する流れ

MCPクライアントに python mcp_server.py をstdioサーバーとして登録してください。エディタを起動したまま、AIに「get_composition_guideを読んで、get_songで曲を取得し、作曲してset_songで反映」と指示します。

画面はAIによる更新を自動で取り込みます。同時編集が競合した場合は自動上書きせず通知します。接続例は同梱のMCP_SETUP.mdを参照してください。

この版の対応範囲

PSGトーン、OPLLメロディ9ch（リズム時6ch＋ドラム）と共通カスタム音色、標準SCC5ch。PSGノイズとドラムキット・音量減衰に対応。OPLLリズム／PSG打楽器のMGS出力、PSGハードウェアエンベロープ、途中テンポ・音色変更、MMLのマクロ・LFOは未対応です。

複合音色

OPLL旋律2chを使用。元パートをAcoustic bass（14）、追加パートをSynthesizer（10）にします。同じ音程・同じタイミングで重ねます。

実験プリセット：音量差は試聴用の調整値です。適用時にノートをコピーします。適用後のノート編集は各パート独立です。

トラックをまとめて編集

音符の開始位置で選択します。96 tick＝4分音符、384 tick＝1小節。ロールの空白でShift＋ドラッグでも範囲を選べます。

倍率は音量値1〜15に適用し、整数に丸めます。聴感上の音圧比ではありません。
