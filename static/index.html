作曲とAI連携

編集

ピアノロールをクリックして追加。ノートをドラッグして移動、右端をドラッグして長さを変更。右クリックまたはDeleteで削除。Ctrl+Z / Ctrl+Yで取り消し・やり直し。

ステップ入力は音名ボタンまたはZ〜Mで入力。トラックは単音です。和音は別チャンネルに分けます。Mはミュート、Sはソロ試聴です。

AIが作曲する流れ

MCPクライアントに python mcp_server.py をstdioサーバーとして登録してください。エディタを起動したまま、AIに「get_composition_guideを読んで、get_songで曲を取得し、作曲してset_songで反映」と指示します。

画面はAIによる更新を自動で取り込みます。同時編集が競合した場合は自動上書きせず通知します。接続例は同梱のMCP_SETUP.mdを参照してください。

この版の対応範囲

PSGトーン、OPLLメロディ9chと共通カスタム音色、標準SCC5ch。PSGノイズ／エンベロープ、OPLLリズム、途中テンポ・音色変更、MMLのマクロ・LFOは未対応です。
