軽量OPLL / Z80キット

現在の曲を出力しています。元の編集用JSONも同梱しています。
ソフトウェアビブラートを省略します。編集用JSONとエディタの曲は変更しません。
OPLL専用・60Hz・曲データ上限15,872バイト。任意のループ範囲は未対応。
曲サイズ等はmanifest.jsonを参照してください。CPU負荷は曲ごとに変わります。
ドライバ301バイト、固定RAM35バイト、CPUスタック最大16バイト＋割り込み側。
実機とゲーム同時動作は未検証です。

ゲームへの仮組み込み
  music-bank.bin を 8000h～BFFFh に連続して配置・マッピングしてください。
  曲は8000h、ドライバはBE00hから。RAM D000h～D022h を専有します。
  このバンクはゲームROMヘッダーや起動処理のない素材で、単独起動ROMではありません。
  1. ゲーム側でMSX-MUSICを検出・有効化し、必要なスロット設定を行う。
  2. HL=8000h として CALL BE00h（init）。初期化はOPLLを書きません。
  3. 安定した60Hzの音楽更新箇所から CALL BE22h（tick）。
     最初のtickがフレーム0です。走査線ごとに呼ぶのではありません。
  4. 停止は CALL BEE8h（stop）。全OPLLチャンネルを消音します。
  5. 全曲ループ試験はinit後に (D008h)=1。既定は0＝最後で終了。
     イントロ付き任意LoopStartはこの初版では未実装です。
  AF/BC/DE/HL/IXは保存します。IY、代替レジスタは使用しません。
  コードを再配置する場合はplayer.asmのORGを変更して再アセンブルすること。
  RAMも固定アドレスなので、ゲームの使用領域と重なる場合はEQUを変更します。
  init/tick/stopを同時に呼ばないでください。割り込みフックは設置しません。
  tick実行中のバンク切替や、別処理からのOPLLポート書き込みは禁止です。
  効果音とのチャンネル共有・予約・復帰は未実装です。
  主処理が遅い時は描画を間引き、音楽の定期更新を優先してください。
  長時間DIや取り逃した割り込みを、このドライバが復元することはできません。
  50Hz機で毎VBlankにそのまま呼ぶとテンポが遅くなります。60Hz更新源が必要です。

OPLLアクセス
  ポート7Ch/7Dhのみを使用。PSG/SCC/OPMへは一切書き込みません。
  アドレス書き込み後に12T、データ書き込み後に84Tの明示的NOP待ち。
  周辺命令・MSXのM1 waitはさらに加わります。
  標準Z80とYM2413がともに約3.58MHzという条件の実装です。
  ターボCPU/R800向けの待ち時間として流用しないでください。
  根拠: Yamaha YM2413 Application Manual, Bus Control / Table II-2
  https://map.grauw.nl/resources/sound/yamaha_ym2413.pdf
